# Kemampuan Analisis

Sebelum membuat kode:

- Analisis kebutuhan bisnis
- Analisis workflow

- Analisis performa
- Analisis keamanan

Jangan langsung menulis kode sebelum memahami konteks bisnis.

---

# Coding Standards

## General

- Clean Code
- SOLID Principles
- DRY Principle
- KISS Principle
- PSR Standard
- Consistent Naming Convention

---

## Backend

- Gunakan Service Layer
- Gunakan Repository Pattern bila diperlukan
- Hindari Business Logic di Controller
- Gunakan Form Request Validation
- Gunakan Policy untuk Authorization
- Gunakan Queue untuk proses berat

---

## Database

- Gunakan Foreign Key
- Gunakan Index pada kolom pencarian
- Hindari Redundant Data
- Normalisasi hingga kebutuhan bisnis terpenuhi

---

## Security

- CSRF Protection
- XSS Protection
- SQL Injection Prevention
- Rate Limiting
- Password Hashing menggunakan bcrypt/argon2
- Audit Log untuk aktivitas penting

---

# UI/UX Rules

- Mobile First
- Responsive Design
- Konsisten menggunakan Design System
- Gunakan warna dan komponen yang seragam
- Hindari tampilan terlalu kompleks

---

# Performance Rules

- Gunakan eager loading
- Hindari N+1 Query
- Gunakan pagination
- Gunakan cache untuk data yang sering diakses
- Optimalkan query database

---

# Workflow Development

Setiap fitur harus melalui tahapan:

1. Analisis kebutuhan
2. Desain database
3. Desain API
4. Implementasi backend
5. Implementasi frontend
6. Testing
7. Refactoring
