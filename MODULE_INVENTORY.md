# Module Inventory: Laravel ERP Refactoring

This inventory lists all application modules currently present in the system, their technical status, coupling dependencies, and estimated refactoring complexity.

| Module | Current Status | Dependency | Refactor Complexity | Refactoring Requirements & Plan |
|---|---|---|---|---|
| **Authentication & RBAC** | Filament default login guard for admin/staff. Livewire-based customer login. | Filament Panel, Livewire | **Medium** | Build unified login views and controllers. Set up standard web middleware to authorize admin/staff vs customers based on role name. |
| **Customer (CRM)** | Managed in admin panel via Filament resource. | Filament Resource | **Low** | Create standard Customer list, detail, and editor pages. Utilizes [Customer.php](file:///d:/xampp/htdocs/eighteen-custom-apparel/app/Models/Customer.php) model. |
| **Product & Catalog** | Product and ProductCategory CRUD via Filament. | Filament Resource | **Low** | Build product listings and product category selectors. |
| **Employee Management** | Employee database CRUD via Filament resource. | Filament Resource | **Low** | Manage employee profiles, roles, and status fields. |
| **Quotations** | Managed in admin. Features dynamic item repeater and "Convert to Order" table action. | Filament Resource | **High** | Requires a Blade form containing dynamic item repeaters with interactive price calculations (subtotal, tax, discount) using Alpine.js. Conversion logic uses [QuotationService.php](file:///d:/xampp/htdocs/eighteen-custom-apparel/app/Services/QuotationService.php). |
| **Order Management** | Custom order creation, player list attachments, and design upload management in admin. | Filament Resource | **High** | Heart of the system. Needs a clean tabbed layout for order details. Requires custom file uploader and interactive tables. Uses [OrderService.php](file:///d:/xampp/htdocs/eighteen-custom-apparel/app/Services/OrderService.php). |
| **Production Tracking** | Displays logs of stages (Draft to Completed). Stage transition triggers status changes. | Filament Resource | **Medium** | Needs a visual progress stepper for order stages, with status transition logs (notes, attachments). Uses [ProductionService.php](file:///d:/xampp/htdocs/eighteen-custom-apparel/app/Services/ProductionService.php). |
| **Employee Attendance** | Daily clock-in/out station with GPS validation and selfie upload. Attendance records in admin. | Filament Resource, Livewire | **Medium** | Convert check-in view to standard Blade + Alpine.js. Integrate HTML5 Geolocation API directly into form submit. Uses [AttendanceService.php](file:///d:/xampp/htdocs/eighteen-custom-apparel/app/Services/AttendanceService.php). |
| **Finance & Payments** | Invoicing and Down Payment/Full Payment logging in admin. | Filament Resource | **Medium** | Invoices list, Payment record form with file upload, and print-ready PDF invoice templates. Uses [PaymentService.php](file:///d:/xampp/htdocs/eighteen-custom-apparel/app/Services/PaymentService.php). |
| **Customer Portal** | Single-page Customer dashboard showing order lists, stages progress, and payments uploads. | Livewire Component | **High** | Migrate from Livewire to standard Laravel MVC. Convert tabs and upload forms into clean Alpine.js dynamic handlers, communicating with standard backend controllers. |
| **Reporting & Dashboards** | Standard Filament dashboard widgets displaying operational stats. | Filament Widgets | **Medium** | Rebuild stats cards (Revenue, Total Orders, Active Productions, Attendance Recap) on the admin/owner home screen. |
